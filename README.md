# SRI NEYA CRANE SERVICES (SNC) — Official Website

Enterprise commercial web platform for **SRI NEYA CRANE SERVICES (SNC)**, Tamil Nadu's leading heavy mobile crane rental, industrial machinery rigging, and 24/7 highway emergency breakdown recovery company.

Designed strictly following the **Caterpillar Corporate Design System** ([careers.caterpillar.com](https://careers.caterpillar.com/en/)).

---

## 🏗️ Key Features
- **Caterpillar Industrial UI/UX:** High-contrast Industrial Yellow (`#FFCD11`), Deep Charcoal Canvas (`#121212`), Caterpillar-style Triangular SNC Badge, and industrial hazard styling.
- **Real-World Operations Gallery (Slide Format):** Interactive slider showcasing authentic ACE crane field projects (30m High-Mast Lighting Towers, TNEB Substation Transformers, Dual-Crane Heavy Tandem Lifts, and Rooftop Telecom Towers).
- **1,500+ Works Completed Real-Time Dashboard:** Filterable and searchable database of 1,542+ completed commercial lifts across Tamil Nadu.
- **Live GPS Fleet Tracking Portal (`/tracking`):** Simulated real-time operations dashboard with interactive regional map canvas showing active mobile cranes and recovery units.
- **24/7 Emergency Breakdown Command Center (`/emergency`):** Priority dispatch interface with direct hotline integration and 1-minute SOS dispatch routing.
- **Interactive Load & Capacity Estimator:** Real-time load calculations recommending appropriate crane models (ACE 14XW, ACE 16XW, 50T Mobile, 80T Rough Terrain, 150T All-Terrain, Tandem Lifts).
- **Interactive HQ Location Map (`/contact`):** Embedded Google Maps centered at **Kullanampatti Petrol Bunk, Ponnagaram, Natham Byepass, Dindigul**.
